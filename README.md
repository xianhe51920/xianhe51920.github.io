## 说明

- 本仓库中的文件均为**构建产物**（站点工程的 `dist` 输出），请勿直接编辑。
- 站点源码与笔记在本地维护，构建完成后同步至本仓库；推送到 `main` 分支后，GitHub Pages 会自动重新构建上线。
- `.nojekyll`：跳过 Jekyll 处理，保证 `_astro` 等以下划线开头的目录能被正常访问（缺失会导致页面白屏）。
- `.gitattributes`：`* -text`，关闭换行符转换，避免构建产物被改写。
